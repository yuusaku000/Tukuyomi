# ツクヨミ

月の下に広がる仮想空間。Unity 6（6000.1.1f1・URP）で作っています。
ミニヤチヨのスマコンの右クリックか、彩葉のスマホの「ツクヨミ」アプリから入ります。

## いまできること（段階4：ヤチヨのライブ）

- **ヤチヨのライブ**（海の AR ライブステージ・3曲で約10分）：曲は**5曲から毎回ランダムに3曲**（1曲目はかならず盛り上がる曲）。音はその場で合成（歌声はなく、メロディは楽器）。歌詞は**空に光る大きな文字**で浮かび、歌いおわると星になってくずれる（画面の下にも小さく出る）
  - 曲：「月灯りパレード」（ポップ）・「八千夜のてがみ」（バラード）・「ヤオヨロ☆ハイパージャンプ」（ロック 172 BPM）・「ネオン金魚の夜」（EDM・ドロップつき）・「千本鳥居ハイウェイ」（速いEDM 160 BPM）
  - **始まり**：大鳥居の高舞台のヤチヨに「ライブをお願い」でいつでも（客席へワープして開演）。**毎晩22時の定期公演**（21時50分にお知らせ）
  - **登場は毎回ちがう**：空に浮かぶ大鳥居の門から降りてくる／空から光の階段を歩いて降りる／海の柱といっしょに舞台から飛び出す
  - **ありえない演出（サビごとにランダム）**：客席をぐるりと巻いて空までのぼる光のリボン・会場ごと大きな光の蓮の花の中に入る・重力が消えて客席ごと浮く・巨大な鳥居が次々と頭の上を飛んでくる（千本鳥居トンネル）・光の竜が会場を巻く・ちびヤチヨの群れ・ヤチヨが光の円盤で客席の上を飛ぶ・島じゅうの明かりが拍で明滅し島から光の柱が立つ・海から巨大なヤチヨが立ち上がる・星の雨・**ライブステージが急に水没する**・**舞台がせり上がる**（光の塔）・空がガラスのように割れて別の色の空になる・ヤチヨが6人に分身・桜吹雪の嵐
  - **間奏・Cメロ**：**ヤチヨが空に弧をえがいて飛んできて、目の前で自分に歌う**（客席のペンライトはピンクにそろい、まわりを花びらが回る）／舞台がせり上がる
  - **バラード**：会場が海の中に沈む（光る魚・泡・光の筋）か、水没か、光の蓮か、星の雨→ 最後は月が大きく近づいて、空へ昇っていく
  - **おわり**：客席みんなのペンライトの光が空へ昇って、ハートの星座になる
  - いつもの光：ムービングライト12台・レーザー・炎の柱・火花の噴水・花火・光る輪と月・左右の大画面（ヤチヨのアップ）
  - **客席**：約120人がペンライトを曲に合わせてふる。**1〜8** で自分のペンライトの色
  - **おまかせカメラ**（**C**。もう一度 C か Esc でもどる）
  - ライブの間は「お知らせ」を出さない。歌詞とヤチヨのことばは画面のいちばん下に。マイクは客席ではなく口もとに向ける
  - **投げ銭**（**T**）：100〜3000 ふじゅ〜。**ミニヤチヨの本物のふじゅ〜**が減る。ヤチヨはライブを止めてお礼を言わない。そのかわり、**ステージに招待されて**20秒ヤチヨのとなりから客席を見られる
  - **コメント**：画面には出さず、舞台のうしろの空を右から左へ流れる（投げ銭は色つきで大きく）
  - メニューの「音量」に「ライブの音楽」

## 段階3でできたこと（釣り堀と休憩）

- **釣り**：釣り堀のふち（か池にせり出した釣り台の上）で **E** → 竿を出す。クリック（か Space）を長押しして、はなすと投げる（長く押すほど遠く。向きはカメラの向き）。浮きが「ちょん」と動くのはまだ、ずぶっと沈んだらすぐクリック。引き合いは、押している間たぐり寄せ、魚が暴れて糸が赤くなったら離す。手もとまで寄せたら釣れて、図鑑と番付に残して池にかえす。E・Esc で竿をしまう
- **魚は20種**（ふつう12・めずらしい5・まぼろし3）。朝だけ・夜だけ・花火の時間だけ・真夜中だけ・夜明けだけの魚もいる。大きさは毎回ちがう（cm）
- **図鑑と大物番付**（**B**・メニュー・釣り堀の立て札）：図鑑は釣った魚の絵・最大の大きさ・釣った数。まだの魚は影と、釣れる時間のヒント。番付は「今週いちばん大きい1匹」で仮想の釣り人20人とくらべる（毎週月曜に新しくなる。先週の順位も出る）。**釣りでふじゅ〜は増えない**
- **座って休む**：ソファ・縁台・池を向いた長椅子の前で **E**（島じゅうのソファと縁台で座れる）。E・WASD で立つ。座ると町のざわめきが小さくなり、しばらく操作しないと画面の表示が消えて景色だけになる
- **釣り堀の庭**：釣り台・蓮の葉と花・柳と紅葉・行灯つきの長椅子・飛び石・鹿威し（カコーン）とつくばい・泳ぐ鯉・夜の蛍・茶屋の風鈴。茶屋「月見茶屋」では甘味が食べられる
- **町の手直し**：通りの上に飾り幕・吹き流し・さかさの和傘・提灯の綱、町なかに松と桜を足した。下町の家の一階の裏とわきに窓と腰板。石畳を明るく暖かい色に。ネオンと縦の看板を増やした。海・川・池の方眼の線を消した。場所の名前は右上に出る
- **ARライブステージ**を1.45倍に広げ、大鳥居から約50m離した
- **遊覧船「月の舟」**：三日月の形の船に、光の帆・提灯・船底に光る青海波。ふだんは海の大鳥居の回廊から東へのびる桟橋に浮かんでいる。切符売り場で **500 ふじゅ〜**を払うとすぐ出航し、空を3周（約4分）して桟橋にもどる。頂上の月見台の切符売り場で払うと、月見台まで迎えに来て、乗ったら3周して月見台にもどる。お客がいなくても毎時0分と30分に1周する。甲板を歩いて下の景色を見られる
- **月見の湯**：中段の西の空き地に露天風呂。岩でかこんだ乳白色のお湯・湯けむり・竹垣・湯屋・石灯籠と行灯・提灯。お湯のふちで **E** → つかる（無料）。地図からワープできる
- **空**：泳ぐ魚とマンタを少し増やした。数分に1回、光るクジラ・大きなクラゲの群れ・光の竜宮の使い・流れ星（夜）のどれかが現れる
- **服の形**：巫女装束（ふだん着の店に3着）・和洋折衷のドレス着物（振袖の店に4着）・十二単ふう（振袖の店に3着）を足した。お店と着がえの画面では、**A・D（←・→）**かボタンで人形を回して見られる
- **町の光飾り**：金魚ちょうちん・浮かぶ灯籠・軒下のネオン管・光の暖簾・光る格子看板・道ばたのぼんぼりを足した
- **月の御殿**の正殿をもう1階高くした（月見の間）。望楼からすけた階段で上がれて、三階も望楼と同じ柱と高欄だけの吹き抜け（ソファと行灯、まわりの景色が見える）。望楼のソファは北の海のほうを向く。御殿のうしろの月見台と頂上の段のすき間をふさいだ
- **ヤチヨ**：海の大鳥居の高舞台にいる。E で話しかけると「夜にして」（「日が沈み、夜がやってきます」→ 空が10秒ほどで21時ごろの夜に。「もとの時間にもどして」かログアウトで現実の時刻へ）・「ライブをお願い」（いまはライブステージへ案内。段階4で Live.Requested につなぐ）・おしゃべり
- **理髪店「月の櫛」**：月見商店街の屋台と、上段の環状通りの西の2か所。髪の色（12色）と形（ショート・ロング・ポニーテール・おだんご・ツインテール）をその場で試して、1回 300 ふじゅ〜で決まる
- お客がいないときの遊覧船は、町の名所をめぐる低空の周だけを回る
- **音**：足音と町のざわめきを本物の録音にした（OpenGameArt.org の CC0 素材：「Footsteps」と「Crowd shouting/speaking ambience」、`Assets/Tsukuyomi/Resources/Sounds`）。祭囃子の笛（「ぴぇー」と聞こえた音）をやめた
- 走っていても石段を登れるようにした（段の角で浮いても地面に吸いつけ、段にぶつかったら持ち上げる）
- 軽くした：遠くの明かりを消す・色だけの部品を1枚の色見本の絵にまとめる・空の魚の部品をまとめる など（1280×720 夜で fps 16〜37 → 20〜43）
- 遊覧船は急に向きを変えない（1秒に9°まで、航路の角もまるめた）
- **遊覧船の航路**：1周目は島の上を高く、2周目は町の名所をめぐる低空（建物より12mだけ上）、3周目は島のまわりの海の上をすれすれに飛ぶ
- **服の店**：巫女装束「神楽屋」・ドレス着物「月下美人」・十二単「雅」を2軒ずつ。品物も足した（巫女5・ドレス6・十二単5）。屋台やほかの店も島のあちこちに増やした（全部で39軒）
- **画面**：上の方位の帯を小さくし、メニューでオン・オフできる。店の名前は 24m 以内の店だけ出す
- **音**：メニューの「音量」で、全体・環境音・効果音を別々に変えられる（ミュートも）。波・水・ざわめきのつなぎ目の「プツッ」と雑音をなくし、遠くて聞こえない音は止める。足音・ボタン・買い物・遊覧船の出航の音を足した
- **花火**（19〜23時）が見えるように直した（火花が一瞬で止まって点になっていた）。島とライブステージのあいだの海の上に上がる
- 大画面と懸造りの展望台のあいだの建物は2階建てまで
- 直したこと：服や飾りのお店で「とじる」を押すと落ちることがあった
- 町の人が川や池に入ったり、石垣の途中に立ったりしないようにした。島の入口（回廊の床）のちらつきを直した

## 段階2でできたこと（商店街と買い物）

- **島じゅうにお店27軒**：下の14軒と、まったく同じ店を下町・中段・上段の環状通りと頂上の参道にもう一度（ふだん着の店の2軒目だけは場所がなく置いていない）。店の上に AR の看板が出て、店先で **E** を押すと入れる
  - 服（23着）：浴衣の店「夕凪」（商店街）・振袖と晴れ着「綾錦」（東西通り）・ふだん着の店「木綿屋」（上段の参道。袴もある）。店ごとに品ぞろえがちがう
  - 飾り（10こ）：小間物屋「星屑」（商店街）・「月の雫」（東西通り）・「花かんざし」（上段の参道）。どこも同じ品ぞろえ
  - 食べ物（38品）の屋台8種：甘味処・たこ焼き・らーめん・クレープと縁日（中段）、すし・焼き鳥・おでん・かき氷と飲み物（下町）。食べ物ごとに手に持つ形と感想がちがう
- **本物のふじゅ〜で買う**：ミニヤチヨの残高から払う（値段は 食べ物 100〜500・飾り 1000〜3000・服 2000〜6000）。買う前に「買いますか？」と確かめる。明細には「ツクヨミ「品名」」と残る。ミニヤチヨが起動していないときは、見るのと試着だけできる
- **着せ替え**：品物をえらぶとその場で試着。買った服と飾りは **C**（またはメニューの「着がえ」）でいつでも着がえられる（服と飾りはタブで切りかえ）。飾りは頭・髪・顔・手・肩・背中に1つずつ。食べ物はその場で食べる
- **町の人たち（約180人）**：自分のまわり（35〜75m）の通りを歩く60人は、離れると自分の近くの通りへ移るので、島のどこにいても人がいる。ほかに、お店の人・店先に2人ずつ・名所ごとに3〜6人が立ち止まっている。30m より遠い人は影と腕振りなし、85m より遠い人は描かない。立ち止まっている人は1つの形にまとめて軽くしている（人なしとくらべて fps は1割弱しか下がらない）
- **吹き出し**：近くの人がときどきしゃべる（「ライブよかった〜！」、お店の人は「おいしいよ〜！」、名所ではその場所の話、夜は花火や夜店の話）。メニューの「吹き出し」でオン・オフ
- **画面の表示**：左上（時刻・場所）と、場所に入ったときの名前は、左下とおなじ小さな文字だけ。一人称のまん中の照準はメニューの「照準」でオン・オフ

- **3人称カメラ**：提灯や看板などの小さな物ではカメラが寄らない。それでも近づきすぎたら自分の人形を隠す（頭が画面いっぱいにならない）

- 持ち物と着ているものは `save.json` に残る（ミニヤチヨ側は払うだけ）

## 段階1.5でできたこと（丸い島と高低差）

- **丸い島に段が重なる**：下町（水路と屋形船）→ 中段（月見商店街・大画面広場・釣り堀と茶屋・千年桜の丘）→ 上段（五重塔・竹林の小道・懸造りの展望台・神楽殿・鐘楼）→ 頂上（月の御殿）。段は石垣と石段（千本鳥居の石段もある）でつながる
- **川**：頂上の近くから湧いて、段のふちで滝になり、下町で水路に分かれて海へ。橋は通りが水を渡る所に自動でかかる
- **町並み**：1〜3階建ての店・町家・蔵・料亭・屋台を通りにそって自動で並べる。看板・日除け・すだれ・のぼり・路地の提灯のジグザグ・渡り廊下・藤棚・番傘の通り・風鈴の回廊
- **生活の小物**：樽・桶・木箱・鉢植え・壺・かご・腰かけ（Poly Haven, CC0）を店先・家のわき・裏に置く（道のまんなかには置かない）。祠とお地蔵さま・井戸・荷車・天水桶・立て看板
- **雰囲気**：空を泳ぐ光る魚とマンタ、夜の花火（19〜23時）、川べりの蛍、朝もや、毎正時の鐘、環境音（波・滝・ざわめき・風鈴・祭囃子。その場で合成）
- **海の上の AR ライブステージ**（土台）：高舞台から大鳥居をくぐる光の橋の先に、結晶の舞台と鳥居の輪。ライブの中身は段階4
- 空は**現実の時刻**とつながる。月は真上にいつも満月
- 2回目からは、前回ログアウトした場所から始まる

### そうさ

| キー | すること |
|---|---|
| WASD・矢印 | 歩く（Shift で走る） |
| Space | ジャンプ |
| マウス | 見回す（画面をクリックすると操作開始。ホイールで近づく・離れる） |
| V | 一人称 ⇔ 三人称（ホイールをいちばん近くまで回しても一人称） |
| E | お店に入る・座る・釣りをする（釣り堀のふちで）・番付の立て札を見る |
| C | 着がえ（持っている服と飾り）。ライブ会場ではおまかせカメラ |
| 1〜8 | ライブ会場で、ペンライトの色 |
| T | ライブ会場で、投げ銭 |
| B | 魚の図鑑と大物番付 |
| M | 地図とワープ |
| Esc | メニュー（視点・音・画質・ログアウト） |
| F3 | デバッグ表示（座標・カメラ・地面の高さと段・場所・見ている物・時刻・fps・版） |
| H | 画面の表示をぜんぶ消す（もう一度 H でもどす。メニューの「表示を消す」でも） |
| F12 | 写真（`ピクチャ\Tsukuyomi` に保存。デバッグ表示も写る） |

地形の手直しを頼むときは、F3 を出してから F12 で撮った写真を渡すと、場所と見ている物がわかる。

## しくみ

- 島の形（段・川・池）は `Assets/Tsukuyomi/Scripts/Island.cs`。ここを変えると地形がまるごと変わる
- 世界は `Assets/Tsukuyomi/Editor/WorldBuilder.cs` がまるごと組み立てて `Assets/Scenes/Tsukuyomi.unity` に保存する（乱数の種が固定なので毎回同じ形）。地形 `TerrainBuilder.cs`、通り・石段・家の配置 `Town.cs`、建物 `Buildings.cs`、名所 `Landmarks.cs`、小物 `Clutter.cs`、軽くするまとめ `Combiner.cs`
- 組み立てたシーンと `Generated` フォルダは毎回作り直すので git に入れない（シーンは約400MBになる）
- 取ってきた素材は `Assets/Tsukuyomi/Imported`（Poly Haven, CC0。Blender で三角形を減らして FBX にした）
- 動きは `Assets/Tsukuyomi/Scripts`：自分（`PlayerController`・`OrbitCamera`）、空（`RealTimeSky`）、画面の表示（`Hud`）、保存（`GameSession`・`SaveStore`）、配信（`StreamStudio`）、人形（`Doll`・`DollAnimator`）
- 見た目のシェーダーは `Assets/Tsukuyomi/Shaders`（水・光る面・星・月・花びら・大画面）
- 保存先：`%APPDATA%\Tsukuyomi\save.json`（環境変数 `TSUKUYOMI_DATA` で変えられる）
- KASSEN（合戦）：入口は竹林の小道の「KASSEN の門」（`Kassen`。地図にも出る）。試合は実行中に作る別のシーンで遊び、島は止めて隠す（空・太陽と月・ポストプロセスだけ残す）。SETSUNA（1対1 の一人称の格闘）は `Setsuna`（進行）・`Setsuna.Stages`（舞台5つ：水上の闘技場・千本鳥居・月面〈重力が軽い〉・桜の丘・夜の竹林。入口の板で選ぶか、おまかせ）・`Setsuna.Combat`（当たり・刹那ガード・コンボ・狐火・コンピューター）・`Setsuna.View`（闘技場・相手の人形・自分の手・カメラ）・`Setsuna.Hud`（表示）・`SetsunaFighter`（技と相手3人）。勝つとふじゅ〜（やさしい 100・ふつう 300・つよい 800）、「つよい」に初めて勝つと狐のきぐるみ（`Catalog.KitsuneKigurumi`、着がえの形 style 4）。記録は save.json の setsunaWins・setsunaLosses

### exe の作り方

```bat
sh build.sh   （Git Bash で。世界の組み立て → exe の書き出し を2回に分けて Unity を動かす）
```

出来上がりは `Build\Tsukuyomi.exe`（環境変数 `TSUKUYOMI_BUILD_OUT` で変えられる）。
本番は `dist\Tsukuyomi.exe`。ミニヤチヨはここを起動する（`TSUKUYOMI_EXE` で変えられる）。
本番に反映するときは、ツクヨミを閉じてから `Build` の中身を `dist` にコピーする。

| tour の `vr:hands・point・click・warp・go・turn・smooth・walk・settings` | `--vr-sim` のときの確かめ（手・板を指す・トリガーで押す・ワープの弧・ワープ・一気に回る・少しずつ回る・視界のふち・VR の設定と取り消し）。記録は `[VR]`・`[VrTest]` |

## 絵や形について

建物・人形・空・水・地形は、基本の形の組み合わせとプログラムで作っています。小物の一部は Poly Haven（https://polyhaven.com）の CC0 素材です。
ヤチヨの色はミニヤチヨの絵（幻影石さんの作品）を参考にしています。個人で楽しむためだけに使い、配布はしません。
